about=TA Task Workspace divides a saved QGIS project into named pieces of work. Each task can retain editable notes, semantic inputs and outputs, dependencies, assigned tools and one or more workspace profiles. Capture explicitly stores selected QGIS panels, toolbars and participating TerraAnalytica context; restore reactivates the nearest saved profile. Local Git history and a hash-chained audit log support recovery and verification when Git is available. Optional ToolSearch learning stores only stable tool identifiers, aggregate counts and timestamps; it never records parameters, layer names, paths or outputs. This experimental beta is local-first and makes no cloud connection.
